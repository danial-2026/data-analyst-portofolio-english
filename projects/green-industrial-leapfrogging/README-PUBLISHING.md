# Green Industrial Leapfrogging Dashboard — Publishing Package

This package is prepared for the public portfolio repository:
`danial-2026/data-analyst-portofolio-english`

## Upload
1. Open the repository on GitHub.
2. Create the path `projects/green-industrial-leapfrogging/`.
3. Upload `index.html` into that folder.
4. Commit to the `main` branch.
5. If GitHub Pages is already enabled for the repository root on `main`, the expected URL is:
   `https://danial-2026.github.io/data-analyst-portofolio-english/projects/green-industrial-leapfrogging/`

## Privacy and research caveats
- This HTML embeds aggregate summaries and country-year Y values needed for interactive charts.
- Do not add raw source documents, unpublished notes, credentials, tokens, or private data to the public repository.
- The page uses Plotly from a public CDN, so charts require an internet connection.
- Review licensing and permissions for the underlying dataset before publishing.
- Reconcile the LightGBM test-R² discrepancy noted in the dashboard before citing model performance in a formal publication.

## Enable / verify Pages
GitHub repository → Settings → Pages. Confirm that the site is published from the `main` branch and repository root. The project URL above will work once the commit is pushed and Pages has deployed it.
