## 3. Publishing / privacy
The public dashboard embeds aggregate indicators and network metrics. Keep raw news/article data and human annotations private unless publication rights are confirmed.

Do not upload raw or restricted datasets, human annotations, private source files, credentials, tokens, or personal information to a public repository unless you have confirmed permission.
